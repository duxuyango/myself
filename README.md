# 杜许阳的个人网站

一个面向初中生的清晰、简洁、带有高级感的单页个人网站模板。
深色主题 + 渐变点缀，纯 HTML / CSS / JavaScript，无需构建工具，可直接部署到 GitHub Pages 等静态托管服务。

## 快速开始

直接用浏览器打开 `index.html` 即可预览。

## 自定义你的信息

所有需要替换的个人信息都用 `XXX` 占位，并在文件中用 `TODO(个人)` 注释标记。
打开 `index.html`，搜索 `XXX` 或 `TODO`，逐项替换即可，主要包括：

| 位置 | 内容 |
| --- | --- |
| `<title>` 与网站描述 | 你的名字与简介 |
| Hero 区 | 名字、打字机显示的标签 |
| 关于我 | 自我介绍（学校、年级）、个人信息卡片 |
| 兴趣与特长 | 学习、运动与生活日常 |
| 成长足迹 | 学习、活动与收获 |
| 我的学习成就 | 地理、物理等学科成绩 |
| 旅游足迹 | 国内、港澳及海外去过的城市 |
| 联系 | 邮箱与社交链接 |

头像占位图为 `assets/img/avatar.svg`，可替换为你自己的照片（建议正方形、约 1:1）。
主题色在 `assets/css/style.css` 顶部的 `:root` 变量中定义（`--accent-a` / `--accent-b`）。

## 部署到 GitHub Pages

1. 将本目录文件推送到一个名为 `你的用户名.github.io` 的仓库；
2. 打开仓库 Settings → Pages，Source 选择 `Deploy from a branch`，分支选 `main`（或 `master`）；
3. 稍等片刻，访问 `https://你的用户名.github.io` 即可看到网站。

## 技术栈

- HTML5 语义化结构
- CSS3（变量、Grid、Flex、动画、响应式）
- 原生 JavaScript（导航高亮、滚动动画、打字机效果、移动端菜单）
